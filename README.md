# Chess Notes & Timer App

## Description
The **Chess Notes & Timer App** is designed to help new chess players learn new techniques, keep track of important game notes, and time their games effectively. Whether you’re a beginner trying to improve your skills or an experienced player looking to practice different strategies, this app is your go-to companion.

The app allows users to:
- Take notes during their chess games (e.g., strategy, tactics, thoughts).
- Use a built-in timer to time their games, making it easier to practice under time pressure.
- Improve their chess skills by reviewing game notes and revisiting past strategies.

## Features
- **Chess Timer**: 
  - Use a simple, easy-to-read timer for each player, with options for setting custom time limits (e.g., Blitz, Rapid).
  - Visual timer display with countdown.
- **Notes Section**: 
  - Take detailed notes during your games.
  - Write down tactics, strategies, or any thoughts about your game to refer back to later.
- **Simple UI**: Clean and intuitive interface that helps new players focus on their game.
- **Customizable Time Settings**: Tailor the timer to your preferred time control.
